# features/lift

Per-lift tab components and hooks for conjugate method analysis, variation radar, and diagnostics.

| File                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LiftTabPanel.tsx`                 | Per-lift tab composing `ConjugateCharts` + `VariationRadarChart` + `DiagnosticsPanel` + `AccessoryTable` with shared variation-highlight state                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `ConjugateCharts.tsx`              | Presentation-only chart for one lift type; renders via shared `shared/charts/MultiSeriesLineChart`; data aggregation in `usePipelineConjugateChartData`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `VariationRadarChart.tsx`          | Per-lift variation radar wrapping `BaseRadarChart` + `TooltipCard`; clickable wedges highlight variations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `DiagnosticsPanel.tsx`             | Diagnostics panel using `usePipelineDiagnostics()` scoped to the active lift and display unit; leads with a current actionable summary that excludes outdated findings and identifies the most common below-range effect with its supporting count; accessible effect-filter buttons expose separate below/above evidence counts so contradictions remain visible; its primary badge reports current actual-vs-expected e1RM while the separately labeled fitted index reports long-term position against the modifier target range, including disagreement cases; outdated rows expose their age while collapsed and include it in the control's accessible name; the expandable evidence strip shows latest date/value, recent trend, observation/comparison counts, expected calculation, and status rationale; also shows explicit retest guidance and reason-specific next actions for unassessed lift variations; each finding independently expands/collapses and its detail area highlights the matching chart variation; badges competition-lift rows with a 🏆 icon (`title="Competition variant"` tooltip) |
| `AccessoryTable.tsx`               | Accessory exercises table grouped by subtype (upper/lower/core/unclassified), each in its own collapsible section with sortable "Exercise", "Effects", "Last performed", and session-count columns (all-time and in-range); takes optional `dateRange` prop; rendered for accessory tab only                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `usePipelineConjugateChartData.ts` | Data aggregation for `ConjugateCharts` (per-lift variations + normalized composite); pipeline-native best-set lookup via `@dyel/api`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `usePipelineVariationRadarData.ts` | Data aggregation for `VariationRadarChart` (last-session details, e1RM snapshots — raw and cross-exercise-normalized)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `usePipelineDiagnostics.ts`        | Consumes pipeline model diagnostics; exposes filtered/aggregated findings scoped to optional `liftType` plus display-ready effect evidence with separate below/above counts, unit-aware evidence rows (formatted effects, source max-effort set, actual/expected e1RM, signed delta, observation age, recent trend, expected calculation, evidence counts, and status rationale), and actionable structured unassessed reasons; unscoped exercise-recognition failures remain on validation surfaces and are not presented as accessory diagnostics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `useAccessoryTable.ts`             | Data aggregation for `AccessoryTable` (groups accessory rows by subtype in fixed order upper→lower→core→unclassified, filters empty groups, formats last-session summaries via `@dyel/api`); computes `effectsDisplay` (comma-joined formatted effects via `formatEffect`, or '—' if empty); takes optional `dateRange` and threads it into `buildAccessoryTableRows` for in-range session counts                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
