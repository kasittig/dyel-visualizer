# features/lift

Per-lift tab components and hooks for conjugate method analysis, variation radar, and diagnostics.

| File                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LiftTabPanel.tsx`                 | Per-lift tab composing `ConjugateCharts` + `VariationRadarChart` + `DiagnosticsPanel` + `AccessoryTable` with shared variation-highlight state                                                                                                                                                                                                                                                                                                                                  |
| `ConjugateCharts.tsx`              | Presentation-only chart for one lift type; renders via shared `shared/charts/MultiSeriesLineChart`; data aggregation in `usePipelineConjugateChartData`                                                                                                                                                                                                                                                                                                                         |
| `VariationRadarChart.tsx`          | Per-lift variation radar wrapping `BaseRadarChart` + `TooltipCard`; clickable wedges highlight variations                                                                                                                                                                                                                                                                                                                                                                       |
| `DiagnosticsPanel.tsx`             | Diagnostics panel using `usePipelineDiagnostics()` scoped to the active lift and display unit; shows fitted strength index against its target range with latest e1RM/observation age as context and explicit stale retest guidance; each finding independently expands/collapses and its detail area highlights the matching chart variation; effect filters are accessible toggle buttons; badges competition-lift rows with a 🏆 icon (`title="Competition variant"` tooltip) |
| `AccessoryTable.tsx`               | Accessory exercises table grouped by subtype (upper/lower/core/unclassified), each in its own collapsible section with sortable "Exercise", "Effects", "Last performed", and session-count columns (all-time and in-range); takes optional `dateRange` prop; rendered for accessory tab only                                                                                                                                                                                    |
| `usePipelineConjugateChartData.ts` | Data aggregation for `ConjugateCharts` (per-lift variations + normalized composite); pipeline-native best-set lookup via `@dyel/api`                                                                                                                                                                                                                                                                                                                                            |
| `usePipelineVariationRadarData.ts` | Data aggregation for `VariationRadarChart` (last-session details, e1RM snapshots — raw and cross-exercise-normalized)                                                                                                                                                                                                                                                                                                                                                           |
| `usePipelineDiagnostics.ts`        | Consumes pipeline model diagnostics; exposes filtered/aggregated findings scoped to optional `liftType` plus display-ready, unit-aware evidence rows (formatted effects, actual/expected e1RM, signed delta, and observation age)                                                                                                                                                                                                                                               |
| `useAccessoryTable.ts`             | Data aggregation for `AccessoryTable` (groups accessory rows by subtype in fixed order upper→lower→core→unclassified, filters empty groups, formats last-session summaries via `@dyel/api`); computes `effectsDisplay` (comma-joined formatted effects via `formatEffect`, or '—' if empty); takes optional `dateRange` and threads it into `buildAccessoryTableRows` for in-range session counts                                                                               |
