# features/lift

Per-lift tab components and hooks for conjugate method analysis, variation radar, and diagnostics.

| File                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LiftTabPanel.tsx`                 | Per-main-lift tab composing `ConjugateCharts` + `VariationRadarChart` + `DiagnosticsPanel` with shared variation-highlight state                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `AccessoryTabPanel.tsx`            | Dedicated table-first Accessories composition: inventory heading, persisted inventory section, date-range control, and synchronized selected-row state; initializes to the first in-range accessory and renders its history                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `WeaknessAccessoryCoverage.tsx`    | Render-only Accessories-tab coverage trace linking detected diagnostic qualities to reviewed accessory-category associations, recent weekly sessions, contributing exercises, expandable evidence, and honest unavailable/no-exposure states                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `AccessoryHistoryChart.tsx`        | Single-series history for the selected accessory; labels the metric in its title, axis, tooltip, legend, and accessible summary, with sparse and empty-range guidance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `ConjugateCharts.tsx`              | Presentation-only chart for one lift type; renders via shared `shared/charts/MultiSeriesLineChart`; data aggregation in `usePipelineConjugateChartData`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `VariationRadarChart.tsx`          | Per-lift variation radar wrapping `BaseRadarChart` + `TooltipCard`; clickable wedges highlight variations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `DiagnosticsPanel.tsx`             | Diagnostics panel using `usePipelineDiagnostics()` scoped to the active lift and display unit; leads with a current actionable summary that excludes outdated findings and identifies the most common below-range effect with its supporting count; accessible effect-filter buttons expose separate below/above evidence counts so contradictions remain visible; its primary badge reports current actual-vs-expected e1RM while the separately labeled fitted index reports long-term position against the modifier target range, including disagreement cases; outdated rows expose their age while collapsed and include it in the control's accessible name; explicitly symptom-limited observations have a visible badge, while expanded evidence preserves all same-day symptom context; the expandable evidence strip also shows latest date/value, recent trend, observation/comparison counts, expected calculation, and status rationale; also shows explicit retest guidance and reason-specific next actions for unassessed lift variations; each finding independently expands/collapses and its detail area highlights the matching chart variation; badges competition-lift rows with a 🏆 icon (`title="Competition variant"` tooltip) |
| `AccessoryTable.tsx`               | Accessory exercises table grouped by explicit coverage category (upper push/pull, muscle groups, core, carries, conditioning, or unclassified), with classification source/confidence visible alongside progress, recency, and session counts; receives display-ready groups from `AccessoryTabPanel`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `usePipelineConjugateChartData.ts` | Data aggregation for `ConjugateCharts` (per-lift variations + normalized composite); pipeline-native best-set lookup via `@dyel/api`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `usePipelineVariationRadarData.ts` | Data aggregation for `VariationRadarChart` (last-session details, e1RM snapshots — raw and cross-exercise-normalized)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `usePipelineDiagnostics.ts`        | Consumes pipeline model diagnostics; exposes filtered/aggregated findings scoped to optional `liftType` plus display-ready effect evidence with separate below/above counts, unit-aware evidence rows (formatted effects, source max-effort set, actual/expected e1RM, signed delta, observation age, recent trend, expected calculation, evidence counts, status rationale, and same-day symptom context with an explicit limitation flag), and actionable structured unassessed reasons; unscoped exercise-recognition failures remain on validation surfaces and are not presented as accessory diagnostics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `useAccessoryTable.ts`             | Data aggregation for `AccessoryTable`; groups rows by explicit accessory category, leaves uncertain exercises unclassified, and formats classification provenance, progress, and last-session summaries from `@dyel/api`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `useAccessoryCoverage.ts`          | Pipeline-context adapter over `buildAccessoryCoverage`; returns distinct in-range session counts and volume by classified category for the compact coverage summary                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `useAccessoryHistory.ts`           | Thin pipeline-context adapter over `@dyel/api`'s selected-accessory history derivation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `useWeaknessAccessoryCoverage.ts`  | Pipeline-context adapter composing diagnostic evidence, reviewed weakness mapping, weekly category exposure, and accessory inventory derivations into display-ready coverage rows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
