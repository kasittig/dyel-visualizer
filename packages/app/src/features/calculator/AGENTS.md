# features/calculator

Rep and strength-score calculator components and hooks.

| File                          | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PlateCalculator.tsx`         | Render-only self-contained plate calculator UI; consumes `usePlateCalculator`, provides accessible target/bar/set controls, readable per-side loading text, and a supplementary responsive mirrored HTML/CSS barbell. It never imports API values directly.                                                                                                                                                                 |
| `RepCalculator.tsx`           | Single render-only Rep Calculator UI for both manual and connected modes; logic is owned by `usePipelineRepCalculator`. Manual mode accepts an e1RM and unit without pipeline data, while connected mode adds exercise/facet selectors and toggleable recorded/projected values via `E1RMCell`.                                                                                                                             |
| `StrengthScoreCalculator.tsx` | Strength score calculator computing Wilks, DOTS, and Schwartz-Malone scores via `useStrengthScores` hook and `@dyel/api`                                                                                                                                                                                                                                                                                                    |
| `usePipelineRepCalculator.ts` | Unified manual/connected Rep Calculator controller. Manual mode owns user-entered e1RM/unit/reps/weight and remains usable for every pipeline status. Connected mode additionally derives exercise choices, facets, recorded/projected estimates, and source labels through `usePipelineModel()` and `@dyel/api`. User-entered calculation fields are not overwritten when connected estimates refresh or the mode changes. |
| `usePlateCalculator.ts`       | Owns plate target/bar/inventory state and adapts `@dyel/api` plate results into grouped side-load text and display strings for `PlateCalculator`.                                                                                                                                                                                                                                                                           |
| `useStrengthScores.ts`        | Computes strength scores (Wilks, DOTS, Schwartz-Malone) by reading pipeline model; accepts bodyweight/unit/gender arguments and returns competitionTotal + scores                                                                                                                                                                                                                                                           |
