# features/calculator

Rep and strength-score calculator components and hooks.

| File                          | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RepCalculator.tsx`           | Render-only Rep Calculator UI; logic owned by `usePipelineRepCalculator` hook. Renders e1RM value via the shared `E1RMCell` component from `shared/components`, which lets the user toggle between actual (raw) e1RM and projected-to-today e1RM.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `StrengthScoreCalculator.tsx` | Strength score calculator computing Wilks, DOTS, and Schwartz-Malone scores via `useStrengthScores` hook and `@dyel/api`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `usePipelineRepCalculator.ts` | Full Rep Calculator controller hook: owns lift-type/exercise/conjugate-facet/reps/weight state, derives e1RM via `usePipelineModel()` and `@dyel/api` selectors; also derives `actualE1rmDisplay` (raw e1RM via `selectBestE1RMPoint`), `projectedE1rmDisplay` (projected e1RM via `resolveE1RMEstimate`-based `estimate`), and `e1rmSourceLabel` ("Based on X" / "Projected from X" caption), all formatted via `@dyel/api`'s `formatWeight` for consumption by `E1RMCell`; also derives a label↔canonical index (`canonicalByLabel`/`exerciseLabels`/`activeLabel`) so the exercise picker can be a searchable `TypeaheadDropdown` instead of a native `<select>` |
| `useStrengthScores.ts`        | Computes strength scores (Wilks, DOTS, Schwartz-Malone) by reading pipeline model; accepts bodyweight/unit/gender arguments and returns competitionTotal + scores                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
