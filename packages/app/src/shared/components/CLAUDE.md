# shared/components

Reusable UI components shared across multiple features.

| File                     | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CollapsibleSection.tsx` | Collapsible titled section; used by `SigmaTab` and `LiftTabPanel`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `DateRangePicker.tsx`    | Date range input using `react-day-picker` + Radix Popover                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `EditableDateChip.tsx`   | Inline date range display in section titles; click to edit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `E1RMCell.tsx`           | Shared inline cell component that toggles between an "actual" (raw) e1RM display value and a "projected" (projected-to-today) e1RM display value on click; renders a small icon with a native `title` tooltip (using `sourceLabel`) only while showing the projected value; when `projectedDisplay` is `null` or equals `actualDisplay`, renders as a plain non-interactive span with no toggle affordance (no-op when there's nothing to project); used by `RepCalculator` and `CoachViewPage`                                                                                                                                                                                                                                                                                                                                                                                          |
| `ErrorBoundary.tsx`      | React error boundary wrapping the root in `main.tsx`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `TypeaheadDropdown.tsx`  | Filterable search input with expandable full-option-list dropdown                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `Table.tsx`              | Shared table primitives (`TableCard`, `Table`, `TableHeadRow`, `TableRow`, `TableCell`) owning the card/border/row/cell styling used by `AccessoryTable`, `DiagnosticsPanel`, and `CoachViewPage`; `TableCell`'s `onSort`/`sortDirection` props render a clickable, arrow-indicated sortable header with the active sort column's label rendered in `var(--accent)` (pair with `shared/hooks/useSortableRows`); `TableCell`'s `className` prop lets callers layer a page-local modifier class (e.g. `CoachViewPage`'s `columnDivider`/`placeholderCell`) on top of the shared `variant` styling; `TableCard` wraps its children in a horizontal-scroll container (`.scrollArea`, `overflow-x: auto`) so wide tables scroll instead of collapsing on narrow viewports; `TableRow`'s `.bodyRow` has a subtle `:hover` tint (lighter than the `selected` tint) as a row-scanning affordance |
