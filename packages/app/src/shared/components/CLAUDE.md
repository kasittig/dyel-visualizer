# shared/components

Reusable UI components shared across multiple features.

| File                     | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CollapsibleSection.tsx` | Collapsible titled section; used by `SigmaTab` and `LiftTabPanel`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `DateRangePicker.tsx`    | Date range input using `react-day-picker` + Radix Popover                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `EditableDateChip.tsx`   | Inline date range display in section titles; click to edit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `ErrorBoundary.tsx`      | React error boundary wrapping the root in `main.tsx`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `TypeaheadDropdown.tsx`  | Filterable search input with expandable full-option-list dropdown                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `Table.tsx`              | Shared table primitives (`TableCard`, `Table`, `TableHeadRow`, `TableRow`, `TableCell`) owning the card/border/row/cell styling used by `AccessoryTable`, `DiagnosticsPanel`, and `CoachViewPage`; `TableCell`'s `onSort`/`sortDirection` props render a clickable, arrow-indicated sortable header with the active sort column's label rendered in `var(--accent)` (pair with `shared/hooks/useSortableRows`); `TableCell`'s `className` prop lets callers layer a page-local modifier class (e.g. `CoachViewPage`'s `columnDivider`/`placeholderCell`) on top of the shared `variant` styling |
