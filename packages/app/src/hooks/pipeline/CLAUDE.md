# hooks/pipeline

Hooks that consume the pipeline model and build datasets for charts.

| File                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| `usePipelineDatasets.ts`           | Calls `usePipelineModel()` and memoizes `buildDatasetsFromModel(model, specs, ui)` to produce chart-ready Recharts rows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `usePipelineTotalChartData.ts`     | Builds total chart data from the pipeline model via `usePipelineDatasets`, applying TOTAL_CHART_SPECS and merging datasets into ChartPoint[] for rendering                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `usePipelineConjugateChartData.ts` | Data aggregation for `ConjugateCharts` (per-lift-type variations + normalized composite via `@dyel/api`'s `conjugateChartSpecs`, plus a pipeline-native best-set-per-date tooltip lookup via `@dyel/api`'s `buildBestSetByLabelAndDate`). No target-normalization selector — the legacy "Competition variation" dropdown was deprecated during the pipeline swap; the normalized series always tracks the model's fixed lift-family baseline.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `usePipelineVariationRadarData.ts` | Data aggregation for `VariationRadarChart` (per-variation last-session details via `@dyel/api`'s `buildLastSessionDetail`, plus both a raw and a cross-exercise-normalized e1RM snapshot via `@dyel/api`'s `snapshotVariationsFromPipeline`/`snapshotNormalizedVariationsFromPipeline`). Baseline-only cross-exercise normalization (to the model's fixed lift-family baseline canonical) was reintroduced after initially being deprecated; `VariationRadarChart` displays only `normalizedSnapshot` — the raw `snapshot` is kept on this hook's return for other potential consumers and is exercised directly by `usePipelineVariationRadarData.test.ts` (real-fixture coverage for both `snapshot` and `normalizedSnapshot`; the `@dyel/core`-vs-pipeline `variationRadarChartParity.test.ts` this was historically diffed against no longer exists — see `HANDOFF.md`). |
| `usePipelineDiagnostics.ts`        | Consumes pipeline model diagnostics and exposes filtered/aggregated findings for `DiagnosticsPanel`; accepts optional `liftType` param to scope returned variants to a single lift (matching variants where `lift` tag equals `lift:${liftType}`), or all variants when omitted                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `usePipelineRepCalculator.ts`      | Full Rep Calculator controller hook: owns lift-type/exercise/conjugate-facet/reps/weight state and derives the e1RM estimate via `usePipelineModel()`; matching/derivation routed through `@dyel/api`'s `repCalculatorSelectors`/`repCalculatorUtils` (`facetsFromTags` retained for facet sync, imported from `@dyel/api`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `useStrengthScores.ts`             | Computes strength scores (Wilks, DOTS, Schwartz-Malone) by reading pipeline model and memoizing `computeStrengthScores`/`getCompetitionTotal` calls; accepts bodyweight/unit/gender as arguments (component-owned state) and returns competitionTotal + scores                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |     |
